# Deep Doc Search (DDS)

Система полнотекстового поиска и анализа рабочей документации (РД).
Индексирует PDF-документы, извлекает текстовый слой и обеспечивает
полнотекстовый поиск через веб-интерфейс.

## Возможности

- Полнотекстовый поиск по содержимому документов (SQLite FTS5).
- Фильтрация по метаданным, извлечённым из имён файлов
  (объект, дисциплина, тип документа).
- Предпросмотр документа с подсветкой совпадений.
- Расширяемая модульная архитектура.
- Веб-интерфейс в стиле VS Code.

## Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone <url> dds
cd dds

# 2. Создать виртуальное окружение
python -m venv .venv
source .venv/bin/activate

# 3. Установить зависимости
pip install -r requirements-dev.txt

# 4. Установить Chromium для smoke-тестов (опционально)
python -m playwright install chromium

# 5. Создать конфигурацию
cp config.json.example config.json
# Отредактировать config.json: указать rd_directory, db_path, пароли.

# 6. Запустить сервер
python run.py
