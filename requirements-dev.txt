# =====================================================================
# Deep Doc Search — зависимости окружения разработки.
#
# Назначение:
#   Единый файл для установки всех зависимостей, необходимых для
#   локальной разработки, тестирования, статического анализа,
#   бенчмаркинга и запуска smoke-тестов. Включает runtime-
#   зависимости (через директиву -r requirements.txt) и добавляет
#   инструменты разработки.
#
# Установка:
#   python -m venv .venv
#   source .venv/bin/activate      # или activate.fish
#   pip install -r requirements-dev.txt
#
# После установки для smoke-тестов требуется браузерный движок:
#   playwright install chromium
#
# Наследование runtime:
#   Первая строка — `-r requirements.txt` — подтягивает runtime-
#   зависимости из requirements.txt. Runtime-пакеты здесь НЕ
#   дублируются: изменения вносятся только в requirements.txt.
#
#   Директива -r резолвит путь относительно текущей рабочей
#   директории. Установка выполняется из корня репозитория,
#   поэтому requirements.txt находится рядом с requirements-dev.txt.
#
# Группировка (после наследования runtime):
#   1. Runtime         — наследуется через -r requirements.txt.
#   2. Testing         — pytest и его расширения.
#   3. Static analysis — линтеры и проверки архитектуры.
#   4. Benchmarking    — замер производительности.
#   5. Smoke tests     — браузерные тесты UI.
#   6. Вспомогательное — парсинг YAML.
#
# Совместимость: Python 3.12+ (см. docs/deployment.md).
# =====================================================================

# 3. Static analysis
#
# Задачи:
#   - Проверка направления зависимостей между слоями (domain,

#   - Проверка отсутствия SQL-строк в контрактах application-слоя.
#   - Статическая типизация.
#   - Форматирование и линтинг.
# ---------------------------------------------------------------------

# Проверка архитектурных контрактов: запрет импортов между слоями

# tools/generate_importlinter_config.py из docs/architecture-decisions/exceptions.yaml.

# Статическая типизация. Критично для контроля протечек типов

mypy>=1.13.0

# Линтер и форматтер. Заменяет flake8 + isort + black.
ruff>=0.1.0

# Хуки для pre-commit (см. .pre-commit-config.yaml).
pre-commit>=3.5.0


# ---------------------------------------------------------------------
# 4. Benchmarking
#
# Задачи:

# ---------------------------------------------------------------------
