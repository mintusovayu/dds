{# Базовый шаблон веб-интерфейса DDS в стиле Visual Studio Code. Все страницы наследуются от этого шаблона через ``{% extends "base.html" %}``. Шаблон определяет компоновку интерфейса в стиле VS Code: +----------------------------------+----------------------------------+ | Область | Описание | +==================================+==================================+ | Activity Bar | Узкая вертикальная панель | | | с иконками-кнопками | | | (поиск, настройки). | +----------------------------------+----------------------------------+ | Sidebar | Боковая панель (фильтры, | | | навигация). | +----------------------------------+----------------------------------+ | Editor Area | Центральная область с вкладками. | +----------------------------------+----------------------------------+ | Status Bar | Нижняя панель статуса, | | | включает информацию о | | | пользователе и кнопку выхода. | +----------------------------------+----------------------------------+ Иконки (плоский дизайн в стиле VS Code): - Все иконки выполнены в виде инлайновых SVG с ``stroke="currentColor"``. - Цвет наследуется из CSS-свойства ``color`` родителя, что обеспечивает автоматическую тематизацию. - Размеры, обводка и заливка задаются в ``base.css`` ТОЛЬКО через классы ``.icon``, ``.icon--sm``, ``.icon--xs``. Контекстные селекторы (например, ``.btn svg``) не используются. - Все декоративные SVG-иконки помечены ``aria-hidden="true"``, чтобы скринридеры не дублировали озвучку. Доступность обеспечивается через ``title`` на кнопке или текстовое содержимое внутри кнопки. Кнопка выхода и автологин по IP-адресу: Кнопка выхода отображается всегда для аутентифицированных пользователей. Контекстная подсказка (``title``) зависит от способа создания сессии: - При парольном входе (``session.is_auto == False``) — стандартная подсказка «Выйти». После нажатия сессия завершается, cookie удаляется; пользователь остаётся неавторизованным. - При автологине по IP-адресу (``session.is_auto == True``) — подсказка «Выход отключит автологин на 8 часов». Нажатие устанавливает opt-out cookie (TTL задаётся константой ``core_config.AUTO_LOGIN_OPT_OUT_TTL_SECONDS``), и middleware ``auto_login_middleware`` пропускает автологин в течение этого интервала. Подсказка делает поведение предсказуемым: без неё пользователь мог бы ожидать, что после выхода он останется неавторизованным навсегда, но через 8 часов автологин снова заработает.
