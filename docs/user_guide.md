## Введение

Deep Doc Search (DDS) — система полнотекстового поиска по рабочей
документации (РД). Система индексирует PDF-документы, извлекает
текстовый слой и обеспечивает быстрый поиск по содержимому.

### Основные возможности

- **Полнотекстовый поиск** по всем проиндексированным документам.
- **Поиск по кириллице и латинице** с поддержкой морфологии.
- **Нечувствительность к раскладке клавиатуры** — визуально похожие
  символы кириллицы и латиницы считаются эквивалентными.
- **Фильтрация результатов** по метаданным, извлечённым из имён файлов:
  объект, дисциплина, тип документа. Поддерживается ввод кодов,
  русских и английских псевдонимов с автодополнением.
- **Режимы поиска**: обычный (содержание + фильтры), только фильтр,
  только содержание.
- **Предпросмотр документов** — растровый рендер страницы PDF
  с подсветкой совпадений (бирюзового цвета), найденных по
  текущему запросу. При открытии страница автоматически
  вписывается по ширине окна; поддерживается масштабирование
  (`Ctrl + колесо`) и панорамирование (перетаскивание правой
  кнопкой мыши).
- **Автоматическая диагностика системы координат подсветки** —
  для документов с нестандартной системой координат DDS
  автоматически корректирует положение подсветки. При
  необходимости пользователь может управлять коррекцией
  вручную (чекбокс «Ротация координат» на вкладке документа).
- **Навигация по страницам**: либо по всем страницам документа,
  либо только по страницам с найденными совпадениями — по
  выбору пользователя.
- **Расширяемая модульная архитектура** для дополнительного анализа.
- **Веб-интерфейс** для поиска и управления.

### Что DDS не делает

- DDS не редактирует документы.
- DDS не хранит оригиналы документов (только метаданные и текст).
- DDS не заменяет систему документооборота.
- **DDS не является полноценным PDF-просмотрщиком.** Предпросмотр
  предназначен для быстрой верификации найденного документа и
  подсвеченного контекста. Для полноценной работы с документом
  (непрерывный скролл, копирование текста, аннотации, печать)
  используйте Acrobat Reader или аналогичный просмотрщик:
  скачайте PDF из результатов поиска.

## Начало работы

### Первый запуск

1. Откройте веб-браузер и перейдите по адресу, указанному
   администратором системы (по умолчанию: `http://localhost:8000`).
2. Если система требует входа, введите логин и пароль,
   предоставленные администратором.
3. На главной странице вы увидите форму поиска и статус сканирования.

### Первое сканирование

Перед первым поиском необходимо просканировать каталог рабочей
документации. Сканирование индексирует все PDF-файлы в каталоге.

1. Перейдите в раздел **Сканирование** через панель настроек
   (кнопка ⚙️ в Activity Bar) или воспользуйтесь соответствующей
   кнопкой в интерфейсе.
2. Нажмите кнопку **▶ Запустить сканирование**.
3. Дождитесь завершения сканирования. Прогресс отображается
   на странице в реальном времени.
4. После завершения первичного сканирования автоматически
   запустится вторичное сканирование, в ходе которого будут
   заполнены поля для фильтрации. Оба этапа отображаются в
   статус-баре и в разделе «Сканирование».

> **Примечание:** Первое сканирование большого каталога может занять
> значительное время (от нескольких минут до нескольких часов
> в зависимости от количества документов).

### Статусы сканирования

| Статус | Описание |
|---|---|
| `idle` | Сканирование ещё не запускалось |
| `running` | Первичное сканирование выполняется |
| `completed` | Первичное сканирование завершено успешно |
| `interrupted` | Сканирование прервано пользователем |
| `error` | Сканирование завершено с ошибкой |

Во время вторичного сканирования в статус-баре отображается
надпись «Сканирование: вторичная обработка…» с процентами
выполнения. После завершения статус снова становится «Завершено».

### Состояние индексации

Помимо статуса сканирования, в разделе **Сканирование**
отображается **состояние индексации** — сводка о том, насколько
полно документы в каталоге РД проиндексированы.

Возможные состояния:

| Состояние | Описание |
|---|---|
| `fully_indexed` | Все файлы проиндексированы, поиск доступен по всем документам. |
| `partially_indexed` | Часть файлов проиндексирована, часть — нет. Требуется сканирование. |
| `needs_update` | Есть новые или изменённые файлы, требующие переиндексации. |
| `empty` | Индекс пуст, но в каталоге РД есть файлы для индексации. |
| `no_source_files` | В каталоге РД нет файлов для индексации. |
| `unknown` | Состояние индексации ещё не рассчитано. Нажмите кнопку «Обновить состояние» для пересчёта. |

## Поиск по документам

### Простой поиск

1. Введите поисковый запрос в поле на главной странице.
2. Нажмите клавишу **Enter** или кнопку **Искать**.
3. Результаты поиска отображаются в виде таблицы:
   - **Документ** — имя файла без пути и расширения (полный путь — в подсказке при наведении).
   - **Страницы** — количество страниц документа, на которых найдены совпадения (например, `13 шт.`). При одной странице — `1 шт.`
   - **Фрагмент** — фрагмент текста с подсветкой совпадений.

**Пустой запрос:**
Если поле основного запроса пустое, поиск всё равно выполняется:
- при наличии активных фильтров будут показаны документы, соответствующие фильтрам;
- при отсутствии фильтров — вообще все документы (аналог «показать все»).

### Синтаксис поисковых запросов

DDS использует синтаксис FTS5 для поисковых запросов.

#### Простое слово

```text
гидрошпонка
```

Находит все документы, содержащие слово "гидрошпонка".

#### Несколько слов (И)

```text
гидрошпонка AND корпус
```

Находит документы, содержащие оба слова.

#### Несколько слов (ИЛИ)

```text
гидрошпонка OR шпонка
```

Находит документы, содержащие хотя бы одно из слов.

#### Точная фраза

```text
"корпус крупного дробления"
```

Находит документы, содержащие точную фразу.

#### Исключение слова

```text
корпус NOT фундамент
```

Находит документы со словом "корпус", но без слова "фундамент".

#### Префиксный поиск

```text
гидро*
```

Находит слова, начинающиеся с "гидро" (гидрошпонка, гидроизоляция и т.д.).

### Нечувствительность к раскладке клавиатуры

DDS автоматически нормализует текст запроса и индексируемых документов,
чтобы поиск был нечувствителен к раскладке клавиатуры. Это значит,
что визуально похожие символы кириллицы и латиницы считаются
одинаковыми.

**Примеры:**

- Запрос `ЕС-423-1` и запрос `EC-423-1` дадут одинаковые результаты.
- Запрос `гидрошпонка` найдёт документы, содержащие `gidroshponka`, и наоборот.

**Как это работает:**

При индексации и при поиске все символы приводятся к нижнему регистру,
а кириллические буквы, имеющие визуально похожие латинские аналоги
(например, `а`→`a`, `в`→`b`, `е`→`e`, `к`→`k`, `с`→`c`), заменяются
на латинские. Поэтому поиск не зависит от того, в какой раскладке
был набран текст или запрос.

**Отображение сниппетов:**

Сниппеты (фрагменты текста в результатах поиска) формируются на основе
нормализованного текста, а затем выполняется обратная замена латинских
букв на кириллические. Это делается для того, чтобы пользователь видел
привычный кириллический текст. Однако такая замена может быть неточной,
если в оригинальном документе действительно были латинские символы,
похожие на кириллические. Это допустимо, так как сниппеты нужны только
для визуального контроля, а полный текст страницы (при открытии
документа) отображается без изменений.

### Фильтры по метаданным

В левой боковой панели расположены фильтры, основанные на
структуре имени файла. Имя каждого PDF-файла имеет формат:

```text
<общий_шифр>-<шифр_объекта>-<номер_дисциплины>-<тип_документа>-<порядковый_номер>-<ревизия>[произвольный текст].pdf
```

Например: `1800-7350-265-DTL-007-5 - копия.pdf`

Из этого имени извлекаются:

- **Объект** (шифр объекта) — второй сегмент, например `7350`.
- **Дисциплина** (номер дисциплины) — третий сегмент, например `265`.
- **Тип документа** — четвёртый сегмент, например `DTL`.

Для каждой из этих категорий в боковой панели имеется **одно поле
ввода с автодополнением**. При вводе текста открывается выпадающий
список, который динамически обновляется после каждого символа.

#### Как работает автодополнение

- **Если вы вводите код** (например, `7350`), выпадающий список
  показывает таблицу из двух колонок:
  - слева — код;
  - справа — русский псевдоним (если есть) или английский.

- **Если вы вводите русский текст** (кириллица), список показывает:
  - слева — русский псевдоним;
  - справа — соответствующий код.

- **Если вы вводите английский текст** (латиница), список показывает:
  - слева — английский псевдоним;
  - справа — соответствующий код.

Выберите нужный вариант из списка, чтобы активировать фильтр.
Фильтры разных категорий объединяются по логическому «И».

#### Снятие фильтра при изменении текста

Если вы изменили текст в поле фильтра (например, стерли его
полностью или начали вводить новое значение), соответствующий
фильтр **автоматически снимается**. Вам не нужно нажимать
кнопку «Сбросить фильтры» — система сама отреагирует на
редактирование.

#### Визуальное подтверждение применённых фильтров

После выполнения поиска:

- поля фильтров, которые были **применены**, окрашиваются
  акцентным цветом (класс `filter-applied`);
- поля фильтров, которые **не были применены**, автоматически
  очищаются.

Это позволяет сразу видеть, какие фильтры участвовали в
последнем поиске.

#### Дополнительные режимы поиска

В боковой панели имеются два чекбокса:

- **Только фильтр** — при активации игнорируется текст в поле
  основного запроса. Поиск выполняется только по активным фильтрам.
  Если фильтров нет, результатом будут все документы.

- **Только содержание** — при активации игнорируются все фильтры.
  Поиск выполняется только по текстовому запросу. При этом
  визуальное выделение фильтров не применяется, даже если в
  полях что-то введено.

Эти режимы взаимоисключающие: при включении одного второй
автоматически выключается.

### Статус-бар после поиска

После выполнения поиска в статус-баре отображается подробная
информация:

> `Запрос: "шпонк*"   Объект: "7350"   Дисциплина: "265"   Тип: "DTL"   Результатов: 12`

Если какая-то позиция не использовалась, вместо значения
отображается прочерк `—`. В зависимости от режима поиска
показатели могут быть следующими:

| Режим | Запрос | Объект | Дисциплина | Тип |
|---|---|---|---|---|
| Обычный (содержание + фильтры) | текст | код или — | код или — | код или — |
| Только фильтр | — | код или — | код или — | код или — |
| Только содержание | текст | — | — | — |
| Пустой запрос + фильтры | — | код | код | код |
| Пустой запрос без фильтров | — | — | — | — |

### Пагинация результатов

Результаты поиска выводятся по **16** на страницу. Для навигации
используйте ссылки пагинации внизу списка результатов.

## Просмотр документов

### Открытие документа

В результатах поиска доступны два способа взаимодействия
с именем файла в столбце «Документ»:

- **Левый клик** по имени файла — **скачивание** PDF-файла.
  Открывается стандартный диалог сохранения браузера; после
  сохранения файл можно открыть в Acrobat Reader или аналогичном
  просмотрщике для полноценной работы.

- **Правый клик** по имени файла — **открытие вкладки предпросмотра
  документа**. Вкладка открывается в центральной области и
  показывает метаданные документа, навигацию по страницам и
  содержимое страницы с подсветкой совпадений. Системное
  контекстное меню браузера при этом подавляется.

Также на вкладке документа доступна навигация по страницам
(см. ниже).

### Режимы просмотра: «Рендер» и «Текст»

Каждая вкладка документа имеет **переключатель режима** в верхней
части панели:

- **Рендер** (по умолчанию) — растровое изображение страницы PDF
  (PNG, DPI 300) с подсветкой совпадений. Режим показывает
  страницу в том виде, в каком она свёрстана в PDF: с графикой,
  таблицами, чертежами. Подсветка совпадений накладывается
  поверх изображения.

- **Текст** — текстовый слой страницы, извлечённый из PDF.
  Отображается в моноширинном шрифте. Удобен для быстрого
  ознакомления с содержимым, копирования текста, использования
  с клавиатуры.

**Состояние режима**:
- Для каждой вкладки режим хранится отдельно. Переключение
  режима в одной вкладке не влияет на другие.
- При открытии новой вкладки применяется режим, который был
  установлен в последней активной вкладке (сохраняется в
  браузере). По умолчанию — «Рендер».
- При закрытии браузера состояние сохраняется и восстанавливается
  при следующем визите.

### Предпросмотр с подсветкой совпадений

При открытии вкладки документа по правому клику из результатов
поиска, DDS автоматически подсвечивает на странице **все найденные
совпадения** текущего поискового запроса.

**Как это работает:**

1. Из сниппетов FTS5, показанных в результатах поиска, извлекаются
   термины — те фрагменты, которые были найдены и подсвечены в
   сниппете.
2. При открытии страницы документа эти термины передаются на
   сервер, который возвращает координаты всех совпадений на
   странице.
3. Совпадения выделяются на рендере страницы прямоугольниками
   с полупрозрачным **бирюзовым** фоном.

**Ограничения подсветки:**

- Подсвечиваются только те страницы, которые были в результатах
  поиска (то есть страницы с найденными совпадениями).
- Если вы переключитесь на страницу, которой не было в результатах
  поиска, подсветки на ней не будет.
- Термины для подсветки соответствуют тому, что FTS5 показал в
  сниппете. Если фраза разбита переносом строки в PDF, подсветки
  может не быть (это редкий случай для технических текстов).
- При выполнении нового поиска подсветка на **уже открытых**
  вкладках не обновляется. Чтобы обновить подсветку, закройте
  вкладку и откройте документ повторно из результатов нового
  поиска.

### Масштабирование страницы

При открытии вкладки документа страница **автоматически
вписывается по ширине** области просмотра (fit-width). Это
значит, что вся страница видна по горизонтали без
горизонтальной прокрутки. Маленькие страницы не увеличиваются
выше своего натурального размера.

Для изменения размера отображаемой страницы в режиме «Рендер»:

- **Ctrl + колесо мыши** — увеличить или уменьшить масштаб.
  Диапазон: от 25% до 400% (0.25 — 4.0).
  При увеличении страница «растёт» из верхнего левого угла.
- **Ctrl + 0** — сбросить масштаб:
  - если вы ещё не меняли масштаб вручную — возврат к автоматическому
    fit-width (страница снова вписывается по ширине);
  - если вы уже меняли масштаб — возврат к 100%.

Масштаб применяется к отображаемой странице и сохраняется
per-tab: в разных вкладках масштаб независим.

### Панорамирование страницы

Если страница не умещается в области просмотра полностью
(например, при увеличении масштаба), её можно перемещать
**перетаскиванием правой кнопкой мыши**:

1. Нажмите и удерживайте правую кнопку мыши в области рендера.
2. Перемещайте курсор — изображение будет «следовать» за
   перемещением. Курсор принимает вид «захвата» (✋).
3. Отпустите правую кнопку мыши, чтобы завершить перемещение.

**Особенности:**

- Системное контекстное меню при правом клике на рендере **не
  появляется** — область рендера перехватывает правый клик для
  панорамирования.
- На остальной части интерфейса правый клик работает как обычно.
- Курсор над областью рендера — «открытая ладонь» (grab),
  во время перетаскивания — «сжатая ладонь» (grabbing).

### Чекбокс «Ротация координат»

На вкладке документа, сразу под переключателем режимов
«Рендер / Текст», расположен чекбокс **«Ротация координат»**.
Он управляет применением коррекции координат подсветки для
документов с нестандартной системой координат.

**Зачем это нужно:**

Некоторые PDF-документы (например, нестандартные CAD-экспорты
или «перевёрнутые» сканы) используют систему координат,
отличающуюся от стандартной. В таких документах координаты
текстового слоя не соответствуют их визуальному положению на
странице — подсветка совпадений отображается не там, где
находится текст.

DDS автоматически определяет такие документы и корректирует
координаты подсветки. Чекбокс «Ротация координат» показывает
текущее состояние коррекции и позволяет управлять им вручную.

**Поведение чекбокса:**

- **Галочка установлена** — коррекция координат применена.
  Подсветка отображается в правильных местах.
- **Галочка снята** — коррекция не применена. Подсветка
  может отображаться со смещением.
- **Чекбокс серый (недоступен)** — либо для текущей страницы
  нет совпадений (подсветка не запрашивается), либо сервер
  ещё не завершил проверку.

**Автоматическое управление:**

При открытии страницы с совпадениями DDS автоматически
проверяет систему координат и устанавливает чекбокс в
нужное положение. Вам не нужно ничего делать — подсветка
изначально показывается в правильном месте, если это
возможно.

**Ручное управление:**

Если вы заметили, что подсветка на конкретной странице
отображается не там, где нужно, попробуйте переключить
чекбокс:

1. Установите/снимите галочку.
2. Подсветка немедленно пересчитается — без перезагрузки
   страницы и без потери текущего масштаба.
3. Оставьте то положение, при котором подсветка совпадает
   с текстом.

**Особенности:**

- Состояние чекбокса хранится **отдельно для каждой
  страницы** вкладки. Переключив его на странице 5, вы не
  измените поведение на странице 6.
- При переходе на другую страницу чекбокс обновляется
  автоматически: сначала выполняется проверка для новой
  страницы, чекбокс принимает её результат.
- Для страниц без совпадений чекбокс недоступен (серый) —
  пересчитывать нечего.

**Подсказка при наведении:**

Если навести курсор на чекбокс, появится подсказка, объясняющая
текущее состояние:

- «Аномалия системы координат (высокая уверенность). Коррекция
  включена автоматически» — DDS уверенно определила аномалию.
- «Возможна аномалия системы координат (средняя уверенность).
  Коррекция включена; при необходимости снимите галочку» —
  DDS обнаружила признаки аномалии, но менее уверенно.
- «Ручное управление коррекцией координат» — вы переключали
  чекбокс вручную.
- «Аномалия системы координат не обнаружена» — DDS не нашла
  признаков аномалии.
- «Подсветка не запрашивалась для этой страницы — нет совпадений» —
  на странице нет совпадений по текущему поиску.

### Навигация по страницам

Для перемещения между страницами документа используйте:

- **Кнопки пагинации** «← Пред.» и «След. →» под метаданными
  документа.
- **Индикатор текущей страницы** в формате «Стр. X из Y».
- **Чекбокс «Навигация по всем страницам»** — переключение
  режима навигации (см. ниже).
- **Прокрутка** — встроенные скроллбары браузера (при
  отображении страницы, не умещающейся в видимую область).
- **Колесо мыши** — вертикальная прокрутка.
- **Стрелки клавиатуры** — `↑`/`↓` для вертикальной прокрутки,
  `←`/`→` — нативная горизонтальная прокрутка (если применимо).
- **PageUp / PageDown** — нативная прокрутка страницы на высоту
  окна.

#### Чекбокс «Навигация по всем страницам»

Чекбокс расположен справа от пагинации и управляет режимом
навигации по страницам.

**Чекбокс активен (по умолчанию):**

- Навигация выполняется по **всем страницам** документа.
- «Стр. X из Y» — X = номер текущей страницы (1-based),
  Y = общее количество страниц документа.
- Кнопки «← Пред.» / «След. →» переключают на предыдущую/следующую
  страницу.

**Чекбокс снят:**

- Навигация выполняется **только по страницам с совпадениями** —
  тем, где были найдены результаты текущего поиска. Количество
  таких страниц совпадает со значением в столбце «Страницы»
  таблицы результатов (например, «13 шт.»).
- «Стр. X из Y» — X = позиция текущей страницы среди страниц с
  совпадениями (1-based), Y = общее количество страниц с
  совпадениями.
- Кнопки «← Пред.» / «След. →» переключают только между страницами
  с совпадениями.
- Если текущая страница не содержит совпадений, отображается
  «Стр. — из Y», кнопка «← Пред.» отсутствует, а кнопка
  «След. →» ведёт на первую страницу с совпадениями.

**Особенности:**

- Переключение режима **не меняет текущую страницу** —
  пользователь остаётся на той же странице, но пагинация
  перерисовывается в новом режиме.
- Состояние чекбокса сохраняется для текущей вкладки до её
  закрытия.
- Если у документа **нет ни одного совпадения** (документ открыт
  без правого клика из результатов поиска, или поиск не нашёл
  ничего в этом документе), чекбокс **недоступен** (серый) —
  навигация возможна только по всем страницам.

### Что делать, если рендер недоступен

Если для конкретной страницы рендер недоступен (например, PDF
повреждён или страница слишком большого формата), DDS
автоматически переключает вкладку в **режим «Текст»** и
показывает текстовый слой страницы.

При этом:

- В верхней части панели отображается сообщение «Рендер недоступен.
  Показан текстовый слой страницы».
- Кнопка «Рендер» в переключателе становится неактивной
  (серой) — переключиться обратно в рендер для этой страницы
  нельзя.
- Кнопка «Текст» становится активной.

Это поведение **не влияет** на другие документы и вкладки:
в них рендер продолжает работать как обычно.

### Скачивание документа

Левый клик по имени файла в результатах поиска запускает
скачивание PDF. Во время скачивания под именем файла
отображается полоса прогресса. После завершения файл
сохраняется в папке загрузок браузера; после этого его можно
открыть в Acrobat Reader или аналогичном просмотрщике.

## Статус сканирования

### Раздел сканирования

Раздел **Сканирование** (доступен через панель настроек) отображает:

- **Фазу сканирования** (primary / secondary).
- **Статус** (running / completed / error).
- **Прогресс** (процент обработки).
- **Счётчики** (всего файлов, обработано, ошибок).
- **Текущий файл** (файл, обрабатываемый в данный момент).
- **Индикацию вторичного сканирования** (когда оно активно).

### Запуск сканирования

1. Откройте панель настроек (кнопка ⚙️).
2. Перейдите в раздел **Сканирование**.
3. Нажмите кнопку **▶ Запустить сканирование**.
4. Первичное сканирование запустится, прогресс отображается.
5. После успешного завершения первичного автоматически начнётся
   вторичное сканирование (обновление метаданных и работа модулей).
   В статус-баре и разделе «Сканирование» будет отображаться
   надпись «Вторичная обработка…» с процентом выполнения.

### Отмена сканирования

1. В разделе **Сканирование** нажмите кнопку **⏹ Отменить сканирование**.
2. Система запросит отмену и принудительно прервёт задачу.
3. Сканирование завершится в течение нескольких секунд.

> **Примечание:** Если файл в момент отмены находится в процессе
> извлечения текста, отмена может занять до 5 секунд.
>
> Отмена не удаляет уже проиндексированные документы.

## Модули

### Что такое модули

Модули — это расширения DDS, которые выполняют дополнительный анализ
документов. Например, модуль `dds_stamp_extractor` извлекает штампы
из PDF-документов.

### Раздел модулей

Раздел **Модули** (в панели настроек) отображает список всех модулей
и их статусы.

### Статусы модулей

| Статус | Описание |
|---|---|
| `active` | Модуль загружен и готов к работе |
| `loading` | Модуль в процессе загрузки |
| `error` | Модуль в состоянии ошибки |
| `migration_error` | Ошибка миграции данных модуля |
| `deactivated` | Модуль деактивирован |
| `shutdown` | Модуль завершил работу |
| `removed` | Модуль удалён из реестра |

### Добавление модуля

Для добавления нового модуля:

1. Разместите каталог модуля в `dds_modules/`.
2. Убедитесь, что модуль содержит `manifest.json`.
3. Перезапустите DDS.
4. Модуль будет загружен автоматически при запуске.

### Удаление модуля

Для удаления модуля:

1. Удалите каталог модуля из `dds_modules/`.
2. Перезапустите DDS.
3. Модуль будет удалён из реестра.

> **Внимание:** Удаление модуля не удаляет данные модуля из БД.
> Для полного удаления данных обратитесь к администратору.

## Администрирование

### Раздел администрирования

Раздел **Система** и **Диагностика** (в панели настроек) доступны
только пользователям с ролью администратора.

В этих разделах отображаются:

- Информация о текущем пользователе.
- Управление сканированием (запуск/отмена).
- Статусы всех модулей.
- Системная информация (пути, диагностика).
- Диагностика кэша индексов слов предпросмотра
  (`word_index_cache`: размер, попадания, промахи).

### Управление пользователями

Пользователи управляются через `config.json`:

```json
{
  "auth": {
    "users": [
      {
        "username": "admin",
        "password": "secure_password",
        "role": "admin"
      },
      {
        "username": "user1",
        "password": "user_password",
        "role": "user"
      }
    ]
  }
}
```

### Роли пользователей

| Роль | Доступ |
|---|---|
| `admin` | Полный доступ: поиск, сканирование, управление модулями |
| `user` | Только поиск и просмотр документов |

## Часто задаваемые вопросы

### Поиск не находит результаты

**Возможные причины:**

1. **Сканирование не завершено.** Проверьте статус сканирования
   в разделе **Сканирование**.
2. **Документ не содержит текстового слоя.** Некоторые PDF-файлы
   содержат только изображения. DDS индексирует только текстовый слой.
3. **Опечатка в запросе.** Проверьте правильность написания.
4. **Регистр не учитывается.** Поиск "Гидрошпонка" и "гидрошпонка"
   даёт одинаковые результаты.
5. **Активны фильтры.** Проверьте, не выбраны ли фильтры или
   чекбокс «Только несоответствующие». Сбросьте их кнопкой
   «Сбросить фильтры» или измените содержимое полей.
6. **Включён режим «Только фильтр»** и поле основного запроса
   заполнено, но фильтры отсутствуют. В этом режиме текст запроса
   игнорируется.

### Как выполнить поиск по всем документам?

Очистите поле основного запроса и убедитесь, что ни один фильтр
не активен (или выключите чекбокс «Только несоответствующие»).
Затем нажмите Enter или кнопку «Искать». Результатом будут все
документы.

### Что означают цветные поля фильтров после поиска?

Акцентным цветом подсвечиваются те поля, фильтры которых были
учтены в последнем поиске. Если поле не подсвечено, его фильтр
не участвовал в поиске (и содержимое было очищено).

### Можно ли искать только по фильтрам без ввода текста?

Да, установите флажок **«Только фильтр»** и нажмите «Искать».
Текст в поле основного запроса будет проигнорирован, даже если
он там есть.

### Можно ли искать только по тексту, игнорируя фильтры?

Да, установите флажок **«Только содержание»**. Фильтры не будут
применены, а их поля не получат цветовое выделение.

### Сканирование занимает много времени

**Рекомендации:**

- Первое сканирование большого каталога может занять значительное время.
- Повторное сканирование обрабатывает только новые и изменённые файлы.
- Не отменяйте сканирование без необходимости.

### Документ не найден после изменения файла

**Решение:**

1. Запустите повторное сканирование.
2. DDS обнаружит изменённый файл по хешу и переиндексирует его.

### Что означает состояние индексации «Состояние не определено»?

**Ответ:**
Состояние `unknown` появляется, когда кэш состояния индексации
пуст или устарел (например, после запуска приложения, если
пересчёт ещё не выполнялся). Это не ошибка, а признак того,
что система ещё не рассчитала актуальное состояние.

**Решение:** Нажмите кнопку **🔄 Обновить состояние** в разделе
**Сканирование**. Система выполнит пересчёт и отобразит актуальное
состояние (например, `fully_indexed` или `needs_update`).

### Как узнать, какие файлы проиндексированы

**Решение:**

Воспользуйтесь поиском с пустым запросом и без фильтров. Вы
получите список всех документов. Для получения полной статистики
обратитесь к администратору.

### Почему на вкладке документа отображается рендер, а не текст?

**Ответ:**
По умолчанию DDS открывает документ в режиме **«Рендер»** —
растровое изображение страницы PDF, наиболее точно
воспроизводящее оригинал (с графикой, таблицами, чертежами).
Такой режим удобен для быстрой верификации найденного документа.

Если вам нужен текстовый слой (например, для копирования текста),
переключите режим кнопкой **«Текст»** в верхней части панели.
Выбор сохранится для последующих вкладок.

### Рендер не отображается (показан текст)

**Ответ:**
Если для конкретной страницы рендер недоступен (повреждён
исходный PDF, страница нестандартно большого формата и т.п.),
DDS автоматически показывает текстовый слой страницы и блокирует
переключатель на «Рендер» для этой страницы. Это ожидаемое
поведение: одна проблемная страница не должна мешать работе
с остальными документами.

### Какого цвета подсветка совпадений на рендере?

**Ответ:**
Совпадения выделяются **бирюзовыми** прямоугольниками с
полупрозрачным фоном. Такой цвет выбран для контраста с
типичным содержимым технических чертежей и текстов и
сохранения читаемости материала под подсветкой.

### Подсветка отображается не на месте. Что делать?

**Ответ:**
Скорее всего, документ использует нестандартную систему
координат, и коррекция координат для текущей страницы
выключена или работает неверно.

**Что проверить:**

1. **Чекбокс «Ротация координат»** (под переключателем
   «Рендер / Текст»). Если галочка установлена — попробуйте
   её снять. Если снята — установить. Подсветка пересчитается
   немедленно.
2. **Наведите курсор на чекбокс** — подсказка покажет текущий
   уровень уверенности диагностики.
3. Если ни одно из положений не даёт правильной подсветки —
   это может быть редкая аномалия, не покрытая диагностикой.
   Сообщите администратору с указанием документа и страницы.

**Важно:** Состояние чекбокса хранится отдельно для каждой
страницы. Переключение на одной странице не влияет на другие.

### Что такое «ротация координат»?

**Ответ:**
«Ротация координат» — это пользовательское название для
**коррекции координат подсветки**. Технически речь идёт о
преобразовании координат из одной системы в другую, но для
пользователя это означает одно: правильно или неправильно
отображается подсветка совпадений на странице.

Чекбокс «Ротация координат» на вкладке документа позволяет
включать и выключать эту коррекцию. DDS обычно управляет
им автоматически — вам не нужно трогать его без необходимости.

### Как увеличить/уменьшить изображение страницы?

**Ответ:**

- **Ctrl + колесо мыши** — плавное изменение масштаба от 25%
  до 400%.
- **Ctrl + 0** — сброс масштаба: до автоматического fit-width
  (если масштаб ещё не менялся вручную) или до 100%.

Масштаб применяется к активной вкладке документа и не влияет
на другие вкладки.

### Что означает «страница автоматически вписалась по ширине»?

**Ответ:**
При открытии вкладки документа DDS подбирает масштаб так,
чтобы вся ширина страницы помещалась в области просмотра —
без необходимости горизонтальной прокрутки. Маленькие
страницы (уже области просмотра) не увеличиваются выше
своего натурального размера.

Если после этого вы изменили масштаб вручную, автоподгонка
отключается. Чтобы вернуть её, закройте и откройте вкладку
заново, либо нажмите `Ctrl + 0` до первого ручного изменения
масштаба.

### Как перетаскивать страницу, если она не умещается?

**Ответ:**
Используйте **перетаскивание правой кнопкой мыши**:
нажмите и удерживайте правую кнопку в области рендера,
перемещайте курсор. Страница будет следовать за курсором.
Отпустите кнопку, чтобы завершить перемещение.

Системное контекстное меню при этом не появляется — DDS
перехватывает правый клик в области рендера.

### Что такое чекбокс «Навигация по всем страницам»?

**Ответ:**
Этот чекбокс (справа от пагинации на вкладке документа)
переключает режим навигации:

- **Активен** (по умолчанию) — переход между всеми страницами
  документа.
- **Снят** — переход только между страницами, на которых были
  найдены совпадения текущего поиска. Количество таких страниц
  совпадает с числом в столбце «Страницы» таблицы результатов
  поиска.

Если у документа нет совпадений, чекбокс недоступен (серый).

### Как скопировать текст из документа?

**Ответ:**
DDS не является полноценным просмотрщиком PDF и не поддерживает
выделение текста прямо на рендере. Для копирования:

1. Скачайте PDF (левый клик по имени файла в результатах поиска).
2. Откройте файл в Acrobat Reader или аналогичном просмотрщике.

Альтернативно: переключите вкладку в режим **«Текст»** и
скопируйте текст оттуда.

### Как добавить новый шаблон штампа (для dds_stamp_extractor)

**Решение:**

1. Создайте JSON-файл шаблона в каталоге
   `dds_modules/dds_stamp_extractor/data/templates/`.
2. Перезапустите DDS.
3. Шаблон будет загружен автоматически.

Формат шаблона описан в документации модуля `dds_stamp_extractor`.

### Система не отвечает

**Решение:**

1. Проверьте, что DDS запущен:

   ```bash
   sudo systemctl status dds
   ```

2. Проверьте логи:

   ```bash
   sudo journalctl -u dds -f
   ```

3. Перезапустите DDS:

   ```bash
   sudo systemctl restart dds
   ```

4. Если проблема сохраняется, обратитесь к администратору.

### Как сделать резервную копию

**Решение:**

Обратитесь к администратору. Резервное копирование выполняется
через копирование файла базы данных SQLite.

### Как обновить DDS

**Решение:**

Обновление выполняется администратором. См. `docs/deployment.md`
для подробных инструкций.
